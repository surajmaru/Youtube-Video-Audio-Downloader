## Installation

### Clone my repo:-
- git clone https://github.com/surajmaru/VIDEO-DOWNLOADER-LOCAL.git

### Download yt-dlp.exe and ffmpeg from my repo release.
- Dont run that exe just put that in a folder like "C:\yt-dlp\yt-dlp.exe" like this then,
- Downlaod the ffmpeg zip:- ffmpeg-2026-01-12-git-21a3e44fbe-essentials_build.zip
- Then unzip the folder in like "C:\ffmpeg".

### Then add both of them to the environment path like:-
- on windows search environment variables open it and click *environment variables*
- then go to system variables -> *Path* then double click it.
- click on *New* and paste the path of those both files ex:-
- C:\yt-dlp
- C:\ffmpeg\bin
- Click Okay and thats it.

### Now open the project folder in vs code and go into the backend folder and run the server like:-
- node server.js

### Then just open the index.html in the brower and it will work 💯
